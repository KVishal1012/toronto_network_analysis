# Assessor guide — do not show before responses

Pass task 1 only if the participant locates source/retrieval information and recognizes the uncertain candidate connection. Task 2 must distinguish a publisher status change from observed construction. Task 3 must leave demolition/cancellation/completion unknown. Task 4 must recognize that confirmation needs identity evidence, not just proximity. Task 5 must explain insufficient observations and no established energy performance.

All five tasks must pass for each of five genuine people on one build. Preserve verbatim responses and observed errors; do not infer a pass from a checkbox alone. If an answer is ambiguous, record it as needing follow-up, not passed. `human_participant` is an assertion by the facilitator, not automatically verified by software.
